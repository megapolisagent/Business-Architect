# CRM «Мегаполис»: листы и поля

> Рабочий файл — `CRM_Мегаполис_шаблон.xlsx` (выпадающие списки уже настроены). Загрузить в Google Drive `05_Продажи_CRM` → «Открыть в Google Таблицах».

| Лист | Назначение | Ключевые поля |
|---|---|---|
| Лиды | Все обращения | см. `Карточка_лида.md` |
| Сделки | Клиенты со статуса S08 (бронь) | ID лида, объект, застройщик, агрегатор, сумма сделки, % комиссии, комиссия ₽, дата ДДУ, дата регистрации, ожидаемая дата выплаты, фактическая дата выплаты |
| Объекты | Лоты для объявлений и подбора | ID, ЖК, застройщик, группа допуска (1/2/3), цена, дата цены, источник цены, быстрая выплата (да/нет), статус проверки Юристом |
| Каналы | Расходы и результат по неделям | неделя, канал, расход ₽, лиды, квалифицированные, диагностики |
| Задачи | Передачи работы | ID, кто заказал, исполнитель, что, срок, статус, ссылка на файл задачи |
| Партнёры | Ипотечные брокеры, юристы, дизайнеры | имя, роль, контакт, рекомендаций отдано, получено |
| Справочники | Списки значений | источники, статусы S01–S99, причины L1–L8 |

**Обязательные поля без исключений:** источник, статус, следующее действие, дата следующего действия.
