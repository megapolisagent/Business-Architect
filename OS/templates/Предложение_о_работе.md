# Предложение о работе (структура, 1 страница)

> Отправляется клиенту в день диагностики. Текст в голосе Марии готовит CMO по ToV, Юрист проверяет формулировки один раз, дальше шаблон используется без изменений.

1. **Ваша задача** — 2–3 строки из брифа.
2. **Что я делаю:** шорт-лист 3–5 проверенных вариантов за 48 часов → показы → переговоры об условиях → сопровождение до регистрации ДДУ.
3. **Что проверяю по каждому варианту:** застройщик, разрешение на строительство, проектная декларация на наш.дом.рф, актуальная цена с датой.
4. **Сколько стоит:** для вас бесплатно — вознаграждение агентства оплачивает застройщик. Цена квартиры — цена застройщика (формулировку утверждает Юрист).
5. **Что нужно от вас:** не обращаться к застройщику напрямую по объектам из подборки до показа — это нужно, чтобы закрепить за вами условия (объяснение фиксации простыми словами).
6. **Следующий шаг:** дата отправки шорт-листа.
7. Реквизиты ИП, контакт.
